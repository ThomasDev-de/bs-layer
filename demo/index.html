Beautiful Sliding Layers

A lightweight jQuery plugin for Bootstrap 5 that creates stunning, mobile-friendly sliding side-panels with built-in Glassmorphism and AJAX support.

Documentation

Glassmorphism

Elegant semi-transparent backgrounds with backdrop blur that automatically adapt to light and dark themes.

Infinite Nesting

Open layers within layers with automatic width management and intelligent z-index handling.

Fully Responsive

Optimized for mobile with full-width transitions and smooth animations tailored for any screen size.

Interactive Examples

AJAX Login

Classic login form loaded via AJAX with nested registration and policy layers.

Custom Width

Demonstrate a layer with a specific width (e.g. 400px) and static backdrop.

No Backdrop

A lightweight layer without a background overlay, allowing interaction with the page.

Quick Start

Include jQuery, Bootstrap, and bsLayer, then initialize via JavaScript:

$('#myButton').bsLayer({
    title: 'My Layer',
    url: 'content.html',
    width: 600
});
